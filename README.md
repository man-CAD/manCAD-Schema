# manCAD Schema 2.0

Windows-Anwendung zum Zeichnen und Simulieren von Elektroschemas.

## Download

[manCAD Schema 2.0.0 herunterladen](https://github.com/man-CAD/manCAD-Schema/releases/download/v2.0.0/ManCADSchema-Windows.zip)

Die ZIP-Datei vollständig entpacken und danach `ManCADSchema/ManCADSchema.exe` starten. Die passende Java-Laufzeit ist enthalten.

## Anmeldung und Lizenz

Ab Version 2 wird vor der Zeichenfläche die Online-Anmeldung und Lizenzprüfung durchgeführt. Zur Nutzung sind eine Internetverbindung sowie ein Online-Konto mit zugeordneter, gültiger Lizenz erforderlich.

[Konto online erstellen oder Lizenz verwalten](https://lizenzen.mancad.ch/account)

## Updates

Die vorhandene Anwendung kann Version 2 über ihre automatische Update-Prüfung beziehungsweise **Hilfe → Updates** beziehen. Die Update-Dateien werden mit dem bisherigen manCAD-Schema-Signaturschlüssel geprüft.

[Neuerungen, Windows-Paket und Prüfbericht](https://github.com/man-CAD/manCAD-Schema/releases/tag/v2.0.0)
